# Aprados · web HTML

Abre `index.html` para navegar. HTML, CSS y JavaScript sin WordPress, Node, compilación ni base de datos.

## Subir al hosting
Descomprime `aprados-web.zip` y sube su contenido a `public_html`, `www` o la carpeta pública de tu hosting. Contiene index.html, creditos.html, favicon.svg, assets/ e images/. Las rutas relativas permiten alojarla también en una subcarpeta.

## Funciones
- Portada con cambio manual de exterior/interior.
- Presentación del servicio con tres capítulos: búsqueda, análisis y compra. En escritorio avanza con el scroll o los controles; en móvil, con los controles táctiles.
- Exploración de zonas con paneles expansibles.
- Ficha de búsqueda con zona, presupuesto y plazo a la vista, y fotografía local que cambia según la zona.
- WhatsApp prepara la consulta para +34 662 00 44 54. El visitante la revisa y la envía desde WhatsApp. No almacena datos ni envía emails.
- Fuentes locales con licencias OFL y animaciones con alternativa de movimiento reducido.

## Contenido
Las fotografías de ambientes son ilustrativas; no representan viviendas en venta. Las fotografías locales proceden de Wikimedia Commons y llevan sus atribuciones en creditos.html. Revisar los textos y documentos legales enlazados a la web actual antes de publicar.

## GitHub
Sube los archivos de la web y su documentación. `.gitignore` excluye herramientas locales, dependencias y el ZIP del hosting. Esta web no necesita `npm install`.
